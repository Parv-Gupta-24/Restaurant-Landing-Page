# Tandoor & Thali — Pure Vegetarian Royal Kitchen

A fully responsive, single-page landing site for **Tandoor & Thali**, an authentic heritage vegetarian restaurant specializing in artisanal fresh paneer dishes, overnight charcoal-simmered Dal Makhani, and clay-oven roasted soya chaap. Built with vanilla HTML, CSS, JavaScript, and Bootstrap 5 (no build tools, no frameworks).

---

## Tech Stack

* **HTML5:** Semantic markup, accessibility attributes (`aria-*`), and schema-ready metadata.
* **CSS3:** Custom design tokens via CSS variables, CSS Grid, Flexbox, responsive typography via `clamp()`, and dark mode support.
* **Vanilla JavaScript:** DOM interaction, theme persistence via `localStorage`, lightbox binding, and reservation form validation.
* **Bootstrap 5.3 (CDN):** Responsive grid, navbar collapse, modal lightbox, and testimonial carousel.
* **Google Fonts:** Fraunces (serif display) & Work Sans (clean sans-serif).
